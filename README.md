# 🚀 Gherbi.AI - Premium AI Engineering Portfolio

Welcome to the source code of **Gherbi.AI**, the personal portfolio of **Gherbi Mohamed Cherif**. 

This project is a meticulously designed, high-performance React web application built to showcase my dual expertise in **Software Engineering** and **Multimodal AI / Audio QA**. Designed with a "Minimalist AI" philosophy, it targets top-tier tech companies in Silicon Valley.

## ✨ Key Features

* **Obsidian Gold Design System:** A custom "Deep Midnight & Amber Gold" color palette using CSS variables, tailored for the modern AI industry.
* **Zero-Lag Custom Cursor:** Engineered using React `useRef` for direct DOM manipulation, avoiding state-based rendering lags.
* **Scroll Reveal Animations:** Smooth, cinema-like section reveals using the native `IntersectionObserver` API.
* **Dynamic Content Filtering:** Instant project categorization (Web Dev, AI & Data, Media) without page reloads.
* **Functional Contact Form:** Integrated with Formspree for real-time, backend-less email forwarding.
* **Mobile-First Architecture:** Fully responsive UI with a custom glassmorphism hamburger menu and optimized touch-device rendering.

## 🛠️ Tech Stack

* **Core:** React.js (via Vite)
* **Styling:** Pure CSS3 (Custom Variables, Flexbox/Grid, Glassmorphism, Keyframe Animations)
* **Typography:** Inter (Primary) & JetBrains Mono (Technical Elements)
* **Hosting:** Vercel

## 💻 Run Locally

To run this project on your local machine, follow these steps:

1. Clone the repository:
  
   git clone [https://github.com/midouma25/gherbi-ai.git](https://github.com/midouma25/gherbi-ai.git)

2. Navigate to the directory:
cd gherbi-ai

3. Install dependencies:

npm install

4. Start the development server:

npm run dev
